# discord-iac

A skill for managing a Discord server as Terraform

We use the following Terraform provider: [`kirchdev/discord`](https://registry.terraform.io/providers/kirchDev/discord/0.10.1).

## Install

```bash
npx skills add realfizz/discord-iac
```

The agent is instructed to make a local git repo, if you would like a published Github repo, you should tell the agent to use the ``gh`` CLI & create a private/public repo.
